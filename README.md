### Movies app


<img width="1920" alt="image" src="https://github.com/user-attachments/assets/b987384a-49d3-48d1-a70a-d925703b4463" />



This project is a full-stack web application built using the Express.js framework for the server-side logic and MongoDB as the persistent database. It functions as a movie list manager, enabling standard CRUD (Create, Read, Update, Delete) operations. The server connects to a MongoDB Atlas cluster, preloads a default list of movies if the database is empty, and utilizes EJS for server-side rendering of the main page. The application defines several API routes to manage the movie data: a GET route to display all movies, a POST route to add new entries, a PUT route to handle updates like "likes" or "dislikes" (incrementing thumbUp or thumbDown counts), and a DELETE route to remove movies from the collection.
